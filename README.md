# Όσα δεν γράφει ο πίνακας — ψηφιακή σχολική εφημερίδα

Next.js 14 (React) + Postgres (Neon) + Vercel Blob. Έτοιμο για Vercel.

## Εγκατάσταση σε 10 βήματα
1. `npm install` (το `postinstall` αντιγράφει το `pdf.worker.min.js` στο `public/`).
2. Ανέβασε τον φάκελο σε αποθετήριο GitHub και κάνε import στο Vercel (Framework: Next.js).
3. Vercel → **Storage** → δημιούργησε **Neon Postgres** και σύνδεσέ το στο project (ορίζει `DATABASE_URL`).
4. Vercel → **Storage** → δημιούργησε **Blob** store και σύνδεσέ το (ορίζει `BLOB_READ_WRITE_TOKEN`).
5. Στο Vercel → Settings → Environment Variables πρόσθεσε:
   - `ENCRYPTION_KEY` = έξοδος του `openssl rand -hex 32`
   - `NEXT_PUBLIC_SITE_URL` = το δημόσιο URL (π.χ. `https://osa-den-grafei.vercel.app`)
6. Τοπικά: `vercel link` και `vercel env pull .env.local`. Πρόσθεσε στο `.env.local`
   `ADMIN_EMAIL`, `ADMIN_PASSWORD` (≥ 10 χαρακτήρες) και `ADMIN_NAME`.
7. `npm run db:setup` — δημιουργεί πίνακες, προεπιλεγμένες ρυθμίσεις/σελίδες, κατηγορίες και τον πρώτο διαχειριστή.
8. Αφαίρεσε το `ADMIN_PASSWORD` από το `.env.local`. Κάνε deploy.
9. Συνδέσου στο `/editor-panel`, άλλαξε κωδικό αν θες και ενεργοποίησε το 2FA (Ασφάλεια και 2FA).
10. Τοπική ανάπτυξη: `npm run dev`.

Ξέχασες τον κωδικό; `npm run reset-password -- email@σχολείο.gr "νέος-κωδικός-10+-χαρακτήρες"`.

## Τι περιλαμβάνει
- **Δημόσιος ιστότοπος** στα ελληνικά: αρχική (δομείται από τον Σχεδιαστή), άρθρα με αναζήτηση/φίλτρα, κατηγορίες, αρχείο τευχών με φίλτρο σχολικής χρονιάς, σελίδες τεύχους, ομάδα, σχετικά, επικοινωνία. Sitemap, robots, Open Graph, JSON-LD, canonical.
- **Αναγνώστης εφημερίδας**: PDF.js + StPageFlip, lazy rendering σελίδων (±2), μικρογραφίες, ζουμ, πλήρης οθόνη, πληκτρολόγιο, αφή, διαδραστικές περιοχές.
- **/editor-panel**: πίνακας ελέγχου με πραγματικά στοιχεία, άρθρα (πρόχειρο/δημοσίευση/προγραμματισμός/προεπισκόπηση), τεύχη (ψηφιακό + εκτυπώσιμο PDF με ξεχωριστό έλεγχο δημοσιότητας), συντάκτες (σειρά, ορατότητα), κατηγορίες, βιβλιοθήκη πολυμέσων, Σχεδιαστής ιστοτόπου, ρυθμίσεις, 2FA.
- **Σχεδιαστής**: ενότητες (προσθήκη/διαγραφή/διπλασιασμός/απόκρυψη/σειρά), απευθείας επεξεργασία κειμένου, εικόνες, φόντα, κενά, προεπισκόπηση υπολογιστή/tablet/κινητού, αυτόματη αποθήκευση πρόχειρου, δημοσίευση με επιβεβαίωση, απόρριψη, ιστορικό εκδόσεων και επαναφορά.
- **Διαδραστικά PDF**: οπτικός επεξεργαστής με σύρσιμο/αλλαγή μεγέθους (κανονικοποιημένες συντεταγμένες 0–1) για σύνδεσμο, άρθρο, βίντεο, ήχο, συλλογή, κείμενο, παιχνίδι, προσαρμοσμένο περιεχόμενο.
- **Ασφάλεια**: scrypt, συνεδρίες στη βάση (HttpOnly, SameSite=Lax), έλεγχος Origin (CSRF), περιορισμός προσπαθειών, TOTP RFC 6238 (μυστικό κρυπτογραφημένο AES-256-GCM), κωδικοί ανάκτησης ως hashes (μίας χρήσης), αποτροπή επανάληψης κωδικού, επαναταυτοποίηση για ενεργοποίηση/απενεργοποίηση, ρόλοι (admin/editor) στον διακομιστή, sanitization HTML/SVG, έλεγχος αρχείων με magic bytes, λειτουργία συντήρησης στον διακομιστή.

## Βίντεο στη θέση εικόνων
Σε κάθε πεδίο εικόνας (εξώφυλλα, φωτογραφίες ομάδας, ενότητες, φόντα, λογότυπα, συλλογές) μπορείς να διαλέξεις βίντεο (MP4/WebM/MOV/OGG, έως 200 MB). Εμφανίζεται προειδοποίηση και μετά ρυθμίσεις: player ή «κινούμενη εικόνα», χειριστήρια, αυτόματη αναπαραγωγή (πάντα χωρίς ήχο), επανάληψη, ήχος, προσαρμογή και εικόνα προεπισκόπησης. Το favicon και η εικόνα κοινοποίησης δεν δέχονται βίντεο. Τα φόντα ενοτήτων παίζουν πάντα χωρίς χειριστήρια και ήχο· με ενεργή την ρύθμιση «μείωση κίνησης» του συστήματος δεν γίνεται αυτόματη αναπαραγωγή.

## Επαναφορά κωδικού με email
Στη σύνδεση υπάρχει το «Ξέχασες τον κωδικό σου;». Στέλνεται email με σύνδεσμο μίας χρήσης που ισχύει 1 ώρα. Ορίστε στο Vercel ΕΝΑ από τα `BREVO_API_KEY` ή `RESEND_API_KEY`, μαζί με `MAIL_FROM_EMAIL` (και προαιρετικά `MAIL_FROM_NAME`). Μετά την επαναφορά κλείνουν όλες οι συνεδρίες και στέλνεται ειδοποίηση. Το 2FA παραμένει ενεργό.

## Λογαριασμοί μαθητών, παιχνίδια και περιπέτειες
- **Εγγραφή**: email, όνομα χρήστη (ψευδώνυμο), κωδικός. Απαιτείται επιβεβαίωση email (χρειάζεται ρυθμισμένο Brevo/Resend), ηλικιακή δήλωση/συγκατάθεση και αποδοχή όρων. Προστασία από ρομπότ: κρυφό πεδίο, ελάχιστος χρόνος συμπλήρωσης, όριο εγγραφών ανά IP, επιβεβαίωση email, προαιρετικός περιορισμός σε domain (π.χ. `sch.gr`) και προαιρετικό Cloudflare Turnstile.
- **Λήψη και εκτύπωση τευχών** (εκτυπώσιμο PDF) απαιτούν λογαριασμό (ρύθμιση: «Ρυθμίσεις ιστοτόπου → Λογαριασμοί»). Όριο 20 λήψεων/ώρα ανά μαθητή. Προαιρετικά και η ανάγνωση.
- **Παιχνίδια**: Κιμωλο-Κουίζ (βαθμολογείται στον διακομιστή), Βρες το ζευγάρι (δωρεάν δοκιμή και για επισκέπτες), Κρεμάλα, Πιάσε τις κιμωλίες. XP, επίπεδα, παράσημα, πίνακες κατάταξης, ημερήσιο όριο 400 XP.
- **Περιπέτειες**: διακλαδούμενες ιστορίες που φτιάχνονται από τον πίνακα διαχείρισης (Περιπέτειες Κιμωλάκη). Επίπεδο ξεκλειδώματος 0 = ανοιχτή σε όλους.
- **Διαχείριση**: ερωτήσεις κουίζ, λέξεις κρεμάλας, περιπέτειες, λογαριασμοί μαθητών (αποκλεισμός/διαγραφή).
- Μετά την ενημέρωση τρέξε ξανά `npm run db:setup` (δημιουργεί τους νέους πίνακες, το αρχικό περιεχόμενο και προσθέτει το «Παιχνίδια» στο μενού).
- Το κείμενο «Απόρρητο και όροι χρήσης» (σελίδα /privacy) είναι πρότυπο: έλεγξέ το με το σχολείο/τον υπεύθυνο προστασίας δεδομένων.

## Σημαντικές σημειώσεις
- **Favicon**: το `public/favicon.png` είναι το ακριβές αρχείο που δώσατε. Τα `apple-touch-icon.png`, `icon-192/512.png` και `favicon.ico` είναι το ίδιο σχέδιο, κεντραρισμένο σε διαφανές τετράγωνο (το πρωτότυπο δεν είναι τετράγωνο).
- **PDF και ιδιωτικότητα**: τα PDF σερβίρονται μέσω `/api/pdf/...` που ελέγχει κατάσταση και δικαιώματα, αλλά τα αρχεία στο Blob έχουν μη μαντέψιμο URL και είναι τεχνικά δημόσια. Οι αποτροπές λήψης (χωρίς κουμπί λήψης, απενεργοποιημένο δεξί κλικ) είναι μόνο για περιστασιακή χρήση. Δεν μπορούν να εμποδίσουν στιγμιότυπα οθόνης ή εξαγωγή περιεχομένου.
- **Όρια**: εικόνες έως 4 MB (όριο Vercel Functions)· PDF έως 150 MB (άμεση μεταφόρτωση στο Blob).
- **Συντήρηση**: οι επισκέπτες δεν λαμβάνουν ποτέ το περιεχόμενο (απόκριση HTTP 200 με σελίδα συντήρησης).
- **Φόρμα επικοινωνίας**: δεν περιλαμβάνεται (η σελίδα δείχνει email/τηλέφωνο/κοινωνικά από τις Ρυθμίσεις).
